# Herbalism theme

Place these five TGA files in this folder:

- BG_Herbalism.tga
- Fill_Herbalism.tga
- Frame_Herbalism_01.tga
- Frame_Herbalism_02.tga
- Frame_Herbalism_03.tga

MoonRange cycles the three frames and uses an additive overlay for the selected spell's in-range indicator. The Moon theme lives in ../Moon/.
