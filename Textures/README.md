# MoonRange artwork

This folder must contain these five original binary TGA textures:

- BG_Moon.tga
- Fill_Moon.tga
- Frame_Moon.tga
- Frame_Moon_Light.tga
- Frame_NoMoon.tga

The addon loads them from `Interface\\AddOns\\MoonRange\\Textures\\`.

**Important:** The original `.tga` binary files are not yet uploaded to this GitHub repository. Use the complete local ZIP build, which includes them. GitHub's text-file connector cannot upload binary textures.
